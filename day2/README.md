# Day 2: Coding Agents in Practice

## Purpose

Day 1 taught the concepts in a chat client (Open WebUI). Day 2 moves those same ideas into a **coding agent**: [Grok Build](https://docs.x.ai/build/overview).

Students will:

- Install and authenticate Grok Build with the class API key
- Reuse **MCP** and **skills** from a coding-agent client (not only Open WebUI)
- Analyze synthetic logs and pcaps to reconstruct a sample network design (later labs)

## Prerequisites

Finish [Day 1](../day1/README.md) first. You should already know what tools, MCP, skills, and agent loops are.
